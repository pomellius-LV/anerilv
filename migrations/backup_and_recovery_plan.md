## 1. СТРАТЕГИЯ РАЗДЕЛЕНИЯ ОКРУЖЕНИЙ (PRODUCTION vs PREVIEW)

В аккаунте Cloudflare уже имеются две базы Cloudflare D1.
Для предотвращения случайной порчи данных строго разделяем их назначение:

| Параметр | Production База (Основная) | Preview / Тестовая База |
|---|---|---|
| **Назначение** | Живые данные сайта `aneri.lv`, актуальные цены и статьи | Тестирование новых функций, миграций, версий |
| **Привязка Pages** | Ветка `main` (Production Environment) | Preview branches (PR / feature-ветки) |
| **Имя переменной** | `DB` | `DB` |
| **Безопасность** | Строгий доступ только для `pomellius@gmail.com` через Cloudflare Access | Доступ для тестирования |

## 2. РЕЗЕРВНОЕ КОПИРОВАНИЕ ДАННЫХ ИЗ CLOUDFLARE D1

Перед применением любых миграций или массовым редактированием цен обязательно создайте снимок (dump) обеих баз.

### Команды экспорта через Cloudflare Wrangler:

```bash
# 1. Экспорт рабочей базы Production
npx wrangler d1 export aneri-production-db --output=./backups/d1_prod_backup_$(date +%Y%m%d_%H%M%S).sql --remote

# 2. Экспорт второй (preview/тестовой) базы
npx wrangler d1 export aneri-preview-db --output=./backups/d1_preview_backup_$(date +%Y%m%d_%H%M%S).sql --remote
```

### Экспорт через Cloudflare Dashboard (Без терминала):
1. Откройте **Cloudflare Dashboard** -> **Workers & Pages** -> **D1 SQL Database**.
2. Выберите нужную базу данных.
3. Перейдите во вкладку **Settings** или **Console**.
4. Нажмите **Export Database** (скачивается SQL-дамп со всеми таблицами и записями).

## 3. ИСХОДНОЕ СОСТОЯНИЕ И БАЗОВЫЙ ОТКАТ (ROLLBACK)

### Откат исходного кода (Git / GitHub):
Если требуется вернуть исходный код приложения до момента внедрения D1:
```bash
# Просмотр истории коммитов
git log --oneline -n 5

# Быстрый откат на предыдущую стабильную версию v1.09
git revert HEAD --no-edit
git push origin main
```
*Примечание: Cloudflare Pages автоматически соберет и опубликует предыдущую версию за 1-2 минуты.*

### Восстановление базы данных D1 из резервной копии:
*Важно: возврат Git-коммита не отменяет изменения в SQL-базе! Для отката базы выполните восстановление из дампа:*

```bash
# Восстановление Production базы из SQL-бэкапа:
npx wrangler d1 execute aneri-production-db --file=./backups/d1_prod_backup_TIMESTAMP.sql --remote
```

Либо в **Cloudflare Dashboard** -> **D1** -> выберите базу -> **Console** -> скопируйте и выполните содержимое резервного файла.

## 4. СТАТИЧЕСКИЙ FALLBACK ПРИ СБОЕ СЕТИ ИЛИ D1

В клиентском коде (`dataService.ts`) реализован отказоустойчивый режим:
- Если Cloudflare D1 временно недоступна, не привязана или возвращает ошибку, сайт **мгновенно и бесшовно использует встроенный каталог `contentData`**.
- Посетители никогда не увидят белый экран, 500 ошибку или пустой прайс-лист.
- Все 3 языка (LV, RU, EN), тексты и контакты продолжают отображаться в полном объеме.
